# 剑叶测量与导出规则

上传分析的入口在 `app/services/analysis_service.py`，侧脉图割及区域组织在
`app/infrastructure/inference/side_graphcut.py`，body局部轮廓修正在
`app/infrastructure/inference/body_contour.py`，性状服务在
`app/services/leaf_analysis.py`，纯几何代码在 `app/domain`。

## 从图片到 JSON

剑叶使用 `models_yolo/leaf/leaf-our-best.pt`，由官方 Ultralytics 加载并执行项目内 OUR
refinement 适配。保存原图尺度的掩膜及连续分数，保留区域轮廓、孔洞和浮点坐标。
维管束先核对 side 归属，再进行区域后处理；维管束多边形仍作为独立标注保留。

默认 `LEAF_POSTPROCESS=graphcut`，保留原配置名，实际启用混合流程：

- side1/side2沿用方案B图割，利用原图颜色、连续分数和区域限制修正边缘、背景粘连与误分孔洞。
- body1/body2采用局部边缘修正与受约束平滑，只调整原有外轮廓，孔洞多边形逐点保留。
  保留原始顶点作为局部回退锚点，边上增加间距不超过2像素的采样点；局部法向搜索最大8像素，
  根据局部Lab颜色差、染色/空腔方向和模型连续分数寻找边缘，连续平滑位移，保护原有突起。
  低对比度处只作轻度几何平滑。局部越界或损失受保护维管束像素时，恢复相关弧段；
  每条外轮廓再检查拓扑、自交、像素及浮点面积变化（最多5%）、变化像素比例（最多15%）。
  无法通过时依次减小该条轮廓的位移或保留原轮廓。最终栅格边界的双向最大位移不超过9像素
  （包含像素栅格化余量），不会新增或删除body孔洞与组件。

body2与body1可包含，不按互斥组织争抢像素；
空腔扩展限于主脉外轮廓内；两个body的最终轮廓还会联合检查，若调整造成新的空腔越界，
两类body回退到原始轮廓，并记录`final_body_containment`。检查使用外轮廓作为包含范围，
不会把这个范围写回区域，也不会为了补齐body而另行填孔。
没有独立填孔步骤或全部填孔开关。重新导出历史 JSON 只计算性状，不重复运行区域后处理。
`region_postprocess.region_methods`记录各标签的实际方法；旧`side_postprocess`兼容键保留。

## 两端与长度

自动模式不依赖 first/end，也不区分解剖学的头尾。先在 side 内部沿可通行区域做两次
最远距离搜索，找到两端；再在原轮廓边界约束下，结合 small/big 的位置排列并生成路径。
中心线以软引导平滑，维管束中心是参考位置，不要求逐个硬穿过，减少 big 内部绕行。
整个过程不生成骨架，也不使用面积或周长反推长度。

最终长度是中心线逐段欧氏距离之和，再按比例尺换算。端部延伸到原始轮廓，
路径不能穿过侧脉折返处的边界。用于导航的小而紧凑维管束空隙可临时填平；
这一步只影响路径搜索，不改变面积统计使用的 JSON 孔洞。

路径不可靠时长度留空，例如：没有 side、主要区域明显断裂、内部通道断裂、
边界延伸失败、路径越界或覆盖不足。具体诊断保留在测量对象和服务日志中，
Excel 不导出测长状态列。不会用 0 或周长÷2替代缺失长度。

## 面积、单位与导出

- 含腔截面面积：`body1 + side1 + side2`。
- 组织净面积：`max(0, body1 - body2 + side1 + side2)`。
- 同一标签有多个实例时选净面积最大的实例；同一拓扑实例的外轮廓面积减孔洞面积，
  周长包含外轮廓和孔洞边界。普通多边形使用浮点坐标的鞋带公式和逐段弦长。
- 比例尺从原图右下象限的红/蓝标尺识别。`scale` 是这条标尺的物理长度，默认500µm；
  `k = scale / 标尺像素长度`。没有有效比例尺时，物理面积、周长、长度留空，计数保留。
- 页面和 Excel 暂不显示或导出 small/big 排列顺序，侧脉测长内部的维管束排序保留。
- 距 side 太远的维管束可能不参与路径引导，但计数和维管束面积仍按全部对应标签统计。

Excel 提供实际 side1/side2 长度，暂不提供排列顺序，移除周长÷2及测长状态。
新前端通过 `/api/excel/columns?group=leaf` 获取列定义，指标卡片使用相同的真实长度字段。
